Qué ofrece la API

API REST (JSON) del TPV virtual PLP para que otros proyectos interoperen con él: cobrar pagos, consultar saldo y retirar fondos, gestionar reembolsos, consultar pagos, y abrir tickets de soporte. Los importes llevan dos decimales y los pagos pueden hacerse en EUR, USD o GBP (por defecto EUR) y cada moneda tiene su propio saldo.

Autenticación

Las rutas protegidas esperan la cabecera Authorization: Bearer <token>. El token se obtiene con POST /login, caduca a los 3600 segundos y después la API responde 401.

Cómo obtener credenciales

Las credenciales (usuario y contraseña inicial) te las facilita el equipo de PLP al dar de alta tu empresa. Puede que se te pida cambiar la contraseña en el primer acceso (POST /profile/password). Si no las tienes, contacta con la persona indicada arriba.

BASE=http://localhost:8000
TOKEN=$(curl -s -X POST "$BASE/login?user=tpv01" \
  -H "Content-Type: application/json" \
  -d '{"password":"mi-contrasena"}' | jq -r .token)

Gestión de errores

Los errores devuelven JSON con code, message y, opcionalmente, details.

{"code":"INVALID_CREDENTIALS","message":"Usuario o contraseña incorrectos."}
HTTPSignificado

403El usuario no está vinculado a una empresa.
404Recurso inexistente o identificador mal formado.
409Conflicto con el estado actual.
422Pago rechazado.

POST/pay

Registra y procesa un pago a partir del ticket del cuerpo, en la moneda indicada (EUR por defecto).

Autenticación: Bearer · comercio (usuario vinculado a empresa)

Cuerpo (JSON)

total_amountnumber · ≥ 0, máx. 2 decimalessíImporte total del pago
currencyEUR, USD, GBP (por defecto EUR)noMoneda del pago
payment_methodcard, cash, transfersíTipo de pago
productsarray · mínimo 1 elementosíCada elemento: product_id (string), name (string), quantity (entero ≥ 1) y unit_price (number ≥ 0, 2 decimales)
payment_dataobjectsíDatos del pago según el método: card_number, expiry, cvv, holder o iban
{
  "total_amount": 12.5,
  "currency": "EUR",
  "payment_method": "card",
  "products": [
    {
      "product_id": "P-123",
      "name": "Café",
      "quantity": 2,
      "unit_price": 1.5
    }
  ],
  "payment_data": {
    "card_number": "4111111111111111",
    "expiry": "12/28",
    "cvv": "123",
    "holder": "J. Pérez"
  }
}

Respuesta 200

{
  "transaction_id": "txn_8f14e45fceea167a",
  "status": "approved",
  "authorized_amount": 12.5,
  "currency": "EUR",
  "balance": 1262.5
}

Errores

HTTPCódigoCuándo
400MALFORMED_BODYCuerpo mal formado o moneda no admitida.
401—Token ausente, inválido o caducado.
403FORBIDDENEl usuario no está vinculado a una empresa.
